## 后续开发注意事项

- 第三步实现真实模型客户端及三 Agent，不返回预制播客数据。
- 第四步复用第二步的会话与快照，实现对话修改和版本管理业务。

- 第六步使用事务互斥，失败时释放任务；recover_interrupted_jobs 只在服务启动且没有其他工作进程执行时调用。
- API 不直接暴露 Artifact.path；校验错误也不能把完整材料或供应商错误正文返回页面或写入日志。

- 单条 TTS 输入限制 600 字符；音频上限、超时与调用次数受配置约束。

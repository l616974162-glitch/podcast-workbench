## 后续开发注意事项

- 第三至六步实现已完成；后续修改必须保持真实调用路径、音色快照、版本保护及完整音频检查。
- recover_interrupted_jobs 只在服务启动且没有其他工作进程执行时调用，CLI 与 API 不要同时运行。
- API 不直接暴露 Artifact.path；校验错误也不能把完整材料或供应商错误正文返回页面或写入日志。
- 材料硬上限目前为 20,000 字符；接口层需同时应用配置中的更低限额，禁止静默截断。
- 单条 TTS 输入限制 600 字符；音频上限、超时与调用次数受配置约束。
- 数据库目前为初始结构，后续改表需设计迁移，禁止通过删除用户数据库来修复问题。
- 本机仍缺两家密钥，用户决定验收时填写。FFmpeg 已由项目依赖提供并验证，显式 FFMPEG_PATH 可覆盖。密钥不发到聊天或提交到 Git。
- 第七步先完成网页风格选择，再接入真实 API；未实现的按钮不得展示为可用功能。
- 第八步补齐复现文档、真实链路验收、录屏与学校模板报告。成员姓名和贡献不得虚构。

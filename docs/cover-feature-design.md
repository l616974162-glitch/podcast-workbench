# 节目封面扩展设计

日期：2026-10-24。用户已选择 A 同屏布局；后续要求改为 LangGraph 自动协同，已实现一次提交后自动制作，真实 Agnes 生图已通过。最新流程见 automatic-collaboration.md。下文保留最初手动方案的设计历史，实际行为以自动协同说明为准。

## 已采纳的方向

节目封面使用 Agnes Image 2.5 Flash，文字仍由 DeepSeek 处理，日常配音继续使用 Edge。默认生成无文字的正方形主题图，标题在页面单独展示。用户确认脚本后手动生成封面，音频与封面分别制作，单项失败不影响另一项。首次不做图文内容配图、上传参考图、图片编辑、自动排版标题或批量候选图。

保留用户已确认的材料优先布局：大材料框、紧凑角色行、统一参数下拉。封面区域放在节目一侧，不挤占材料输入空间。每次一张，默认 1K、1:1；风格提供插画、摄影感、极简抽象。生成前可编辑画面描述，生成后可下载、重新生成；旧封面在新任务失败时保留。

## 拟新增节点与分工

现有 researcher → writer → reviewer 三节点不变。新增独立的封面策划节点 cover_planner，使用 DeepSeek，将当前版本的标题、简介、脚本主题和用户画面要求转成生图提示词。它仅在用户点击封面功能时运行，不在每次修改或配音时自动执行。

策划输出以完整 prompt 和简短 rationale 表达主题、主体、构图与色彩，限定依据节目内容，不把视觉隐喻当作事实。Agnes image 工具接收最终 prompt，工具不计为另一个 LLM Agent。当前代码已有四个 LLM Agent；封面策划是独立任务，原 LangGraph pipeline 仍是三个节点。

建议先提供“整理画面描述”，让用户确认或编辑提示词，再点击“生成封面”。已有清楚提示词时可直接生成，避免每次重试图像都重复调用 DeepSeek。

## 用户流程与状态

材料 → 三 Agent 生成并审校脚本 → 用户查看脚本 → 可分别制作音频、策划封面。

封面：整理描述 → 编辑 prompt／选择风格 → 生成 → 下载或重新生成。

状态必须区分无脚本、未生成、策划中、描述就绪、生成中、已生成、失败、对应旧脚本版本。生成中的说明跟随真实任务，不虚构百分比。任务期间禁止同一会话重复提交。失败显示可读错误并保留脚本、音频与已成功封面。脚本生成新版后标记旧封面，提示用户选择是否更新，不自动消耗图像服务额度。

## 后端增量方案

- 在 config.yaml 增加封面策划提示词及图像工具配置；新增密钥仅从本地 AGNES_API_KEY 读取。未配置时封面功能提示配置，原文字与配音继续使用。
- 独立的封面计划请求生成结构化提示词；生成图像请求携带明确 revision_id、prompt 和画风，复用现有任务查询、trace_id 和会话互斥机制。不得将新操作直接落入现有三节点制作分支。
- Artifact 新增 image 类型和相应图片 MIME，保存图片尺寸、模型和脚本版本关系；会话单独保存最新成功封面，不能复用 published_audio 字段。
- 版本明确的图像产物通过既有受控产物接口返回 URL 并下载；图像任务只返回自己的产物，旧任务不混入后来生成的图片。
- 校验服务响应、图片类型与实际内容，限制下载字节数，不向图片下载地址转发鉴权，不接受用户提供的任意下载 URL。
- 真实日志串联 cover_planner 的 LLM 调用和 Agnes image 工具调用；不记录密钥、授权头、签名地址或完整原文。

实施使用 POST /chat 的 plan_cover／generate_cover 动作与既有任务查询；图片和策划结果独立存储，不覆盖音频。

## Agnes 官方接口核实

已于 2026-10-24 查阅官方说明：

- 模型：agnes-image-2.5-flash。
- POST https://apihub.agnes-ai.com/v1/images/generations，Bearer 鉴权。
- 参数 model、prompt、size；默认使用 size=1K、ratio=1:1（1024×1024）。
- URL 输出使用 extra_body.response_format=url，不在顶层传 response_format；也支持文生图 Base64 输出。
- 当前官方价格页显示图像模型优惠价格为零；实际权限、配额与账单以账户为准，不在产品中承诺永久免费。

来源：https://wiki.agnes-ai.com/en/docs/agnes-image-25-flash ，https://wiki.agnes-ai.com/en/docs/pricing 。本轮未访问用户密钥、未创建 API Key、未进行真实生图。

1. 用户选择本地交互稿中的页面布局，持久化设计系统，避免重复改动已认可的材料区。
2. 扩展图片数据模型和版本规则；用失败不覆盖、版本不混淆、类型与下载限制等测试验证。
3. 新增 cover_planner 与 Agnes 工具，验证请求格式、错误分类和日志字段；隔离网络测试只用于开发，不作为真实服务证据。
4. 接入页面策划、编辑、生成、预览、下载、失败重试、旧版提示；覆盖键盘操作与移动屏幕。
5. 用户将密钥填入本地 .env，进行一次真实封面生成，验证图像内容、下载和 trace_id；再验收完整节目音频＋封面展示。

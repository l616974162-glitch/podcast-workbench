# 课程录屏准备提纲

当前仅后端预览，不是已经录制的视频。先完成前端设计与对接、真实供应商验收，再按以下结构录制 1080p MP4，总计约 6–8 分钟。

1. 端到端演示约 2 分钟：浏览器粘贴材料、展示三个阶段、生成并播放双人音频，画面出现 trace_id。当前没有网页，不能用自动测试画面代替。
2. 架构讲解约 2–3 分钟：说明 pipeline 顺序、三个 Agent 的提示词与结构、config.yaml 护栏、Qwen-TTS 的非兼容协议、JSON 地址下载和 Artifact；如实说明直接 LangGraph 与任务书封装的差异。
3. 可观测证据约 1 分钟：使用本次演示的真实 trace_id，在 logs/agent.log 核对 run → node → llm／tool → audio_merge。cache.hit 只能证明缓存复用，不能冒充真实语音调用。
4. 分工自述约 1 分钟：实际成员逐一说明承担的具体模块／文件。待用户提供真实成员与贡献后填入，不编造分工。

完成后以“组号-场景名.mp4”命名，并准备学校模板课程报告与现场验收记录。本预览仓库没有视频、学校模板报告或教师签字记录。

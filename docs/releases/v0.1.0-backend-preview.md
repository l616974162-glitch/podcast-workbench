# v0.1.0-backend-preview 后端第一版备注

日期：2026-10-24。发布范围：可供本地配置密钥后验收的后端预览版。源码、测试、依赖锁定与操作说明一并提交。

## 已完成

- DeepSeek 资料整理、播客编剧、内容审校三 Agent 的 LangGraph pipeline。
- 脚本预览、连续修改、部分设置合并、不可变版本快照、UTF-8 脚本导出。
- Qwen-TTS 自定义协议与注册、真实服务请求代码、受限音频下载。
- 双音色分段制作、FFmpeg 格式统一、顺序合成、实际时长、片段缓存。
- SQLite 会话、任务互斥、后台状态、失败保护及中断恢复。
- FastAPI 创建／修改／渲染、进度、会话、产物、Range 播放与下载接口。
- 命令行制作入口，无需网页即可提交同一套请求；可用输入示例。
- 安全 JSONL 日志、trace_id／session_id、环境检查、配置纪律。

## 验证情况

- 76 项 pytest 通过；ruff 通过；mypy 检查 18 个源文件通过。
- LangGraph、SQLite、FastAPI 和随包 FFmpeg 实际运行；供应商网络在测试中隔离。
- 已修复首次失败无法原会话重试、音色选择不保留、异常模型响应分类不正确等自查问题。
- 用户决定稍后在本地填密钥，因此真实 DeepSeek／千问鉴权、额度、音色质量及生成时长尚未验收，不冒充已通过。

## 后续注意事项

1. 按 docs/acceptance.md 在本机填密钥并验收；不要将 .env、生成音频、数据库或日志提交 Git。
2. 本次为后端预览标签，不代表课程完整第一版已验收。
3. 用户确认前端设计后才进行第七步，不要提前挂载网页、开启 CORS 或部署公网。
4. CLI 与 HTTP API 只运行一个进程，不启用多 worker；恢复任务不自动续跑。
5. 模型或音色不可用时修改 .env／config.yaml 并做真实验证，不能用预制输出代替。
6. 当前源材料上限 20,000 字符，语音单片 600 字符、最多 48 片，音频限制 20 MiB；目标时长不承诺精确到秒。
7. 当前直接使用 LangGraph，由用户明确选择，与原任务书指定 langraph_agent 封装存在差异，须如实解释。

安装和入口见 README.md；阶段进展见 docs/progress.md；自查证据见 docs/backend-review.md。

## Edge 配音扩展

用户要求日常使用免费 Edge 语音。当前默认 TTS_PROTOCOL=edge_tts，不需要 DashScope Key；通过 TTS_PROTOCOL=qwen_tts 保留课程千问主链路。DeepSeek 密钥仍需用户本地填写。

- 配音仍由 AudioRenderer 工具节点管理，三 Agent 职责未变化。
- Edge 使用晓晓／云希默认音色；MP3 流转换为 WAV 后进入原合成流程。
- 缓存区分引擎，产物记录实际 tts_protocol，错误不自动回退到付费服务。
- 84 项自动测试、ruff、mypy 通过，覆盖原千问和新增 Edge；Edge 真实试音 9.24 秒，未调用 LLM。
- 前端仍不连接 API，后续对接时读取引擎及音色默认值，不能把千问音色直接用于 Edge。
- 原 v0.1.0-backend-preview 标签不改写。当前扩展详见 edge-tts.md。

# 网页与后台对接记录

2026-10-24，用户选定 C 版文稿编辑室，并授权连接后台。原静态设计保留在 design/editorial；正式资源位于 src/podcast_workbench/static，由 FastAPI 同源提供，无独立前端构建步骤。

## 启动与验收

在仓库目录执行：

```powershell
& .\.venv\Scripts\python.exe -m uvicorn podcast_workbench.api:create_app --factory --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000/ 。当前默认 Edge TTS，无需 DashScope 密钥。将 DEEPSEEK_API_KEY 填入本地 .env 后重启后台，密钥不进入网页、不提交仓库。

1. 粘贴材料，选择听众、风格、时长和两个不同音色，勾选先预览脚本。
2. 生成脚本，观察整理、编写、审校实际阶段，检查脚本、提纲与审校摘要。
3. 点击生成音频，观察配音与合成阶段，试听两种声音并下载 WAV 与文本。
4. 保持预览勾选，输入修改要求；脚本版本增加，旧音频仍可试听，并提示生成新版音频。
5. 修改左侧音色，点击应用所选音色；只调用配音工具，不重写脚本。
6. 刷新页面，恢复当前浏览器最近会话；后台活动任务继续查询。
7. 网络查询失败提供重新查询，后台制作失败保留已有内容。换材料通过新建节目操作。

原材料创建后只读。任务运行时禁用重复提交和新建节目；主按钮在已有会话时按当前设置重新制作脚本，会再次调用 DeepSeek。目标时长只是参考，播放器旁展示成品实际秒数。浏览器只保存最近会话编号，不保存密钥。

请求超时不等同于任务失败，提交响应丢失时不要立即重复发起。已有会话可刷新恢复；首次创建若响应完全丢失，则可能需要从本地日志中的会话编号排查。当前未实现幂等提交和会话列表。

- Python：86 项测试通过，包括静态入口、同源资源、配置文件不公开及原后端回归。

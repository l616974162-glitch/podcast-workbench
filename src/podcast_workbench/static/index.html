怎样制作一期节目

  1. 粘贴具体材料，选择听众、风格和目标时长。
  2. 填写两人称呼、选择音色，直接制作或先预览脚本。
  3. 查看脚本、提纲和审校结果，再生成双人音频。
  4. 长脚本可展开阅读，也可导出完整 Word 文档。
  5. 通过对话修改，或只调整两个角色的音色。

DeepSeek 负责整理、编写和审校；Edge TTS 负责双人配音。更换原材料请新建节目。页面会恢复最近一次会话，任务期间请勿关闭后台。
